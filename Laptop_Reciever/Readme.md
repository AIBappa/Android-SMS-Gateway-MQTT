Functionality
Python Server to start Receiver at Local Laptop end for SMSs being received on mobile. Both Local laptop and mobile are on same Wi-Fi-network.

Mobile is configured to send via HTTP whilst Laptop is configured to receive the SMS data  on port 8080.

Future updates required for old mobile SMS receiver.
- Cut phone calls after missed call.
- Clean call log after x amount of days.
- Move SMSs to SD Card storage.
- Clean SMS SD Card Storage after y amount of days.
